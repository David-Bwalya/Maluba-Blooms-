Stock changes are saved to the website’s GitHub repository, so this page needs a GitHub access token. It stays in this browser and is only sent to GitHub.

How to get a token
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
  2. Repository access: Only select repositories → Maluba-Blooms-.
  3. Permissions: Contents → Read and write. Leave everything else as No access.
  4. Generate it, copy it, and paste it above. Treat it like a password.

Switch a product off and it disappears from the website until you switch it back on.
